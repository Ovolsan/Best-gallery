# Best gallery

Плагин для **exteraless**, который добавляет в галерею вложений три действия: удалить выбранные файлы, отправить и удалить, отправить файлом и удалить.

**Версия: 20261011.** Проверено на exteraless `12.10.6-00c14f4` ([12.10.6-beta14](https://github.com/exteraless/exteraless/releases/tag/v12.10.6-beta14)), Android 11.

[Скачать плагин](https://github.com/Ovolsan/Best-gallery/releases/latest/download/best_gallery.plugin) · [RAW-ссылка](https://raw.githubusercontent.com/Ovolsan/Best-gallery/main/best_gallery.plugin) · [Релизы](https://github.com/Ovolsan/Best-gallery/releases)

## Возможности

| Кнопка | Действие |
| --- | --- |
| **Удалить с устройства** | Удаляет выбранные фото и видео из галереи устройства без отправки. |
| **Отправить и удалить** | Отправляет выбранные файлы штатным способом как фото или видео. После подтверждения отправки всех файлов удаляет оригиналы с устройства. |
| **Отправить файлом и удалить** | Использует штатную отправку «без сжатия» — документами. После подтверждения отправки всех файлов удаляет оригиналы с устройства. |

- **Три кнопки рядом с ⋮.** Положение не зависит от длины строки «Выбрано…» и количества выбранных файлов.
- **Кнопки остаются сверху.** При разворачивании галереи свайпом они переходят в верхнюю панель и остаются доступными при прокрутке.
- **Единый стиль иконок.** Штатная корзина exteraless; изображение с пикселями или файл, стрелка и корзина для двух режимов отправки.
- **Отправка нескольких файлов.** Сохраняются штатные подпись, порядок, группировка и доступные параметры медиа.
- **Удаление после отправки всего набора.** Частичного подтверждения недостаточно: плагин ждёт подтверждения каждого выбранного файла.
- **Сохранение оригиналов при ошибке или отмене.** Если отправка не подтверждена полностью, удаление не начинается.
- **Удаление без повторного окна.** Достаточно один раз разрешить доступ к нужной папке; разрешение действует и для её вложенных альбомов.
- **Раздельные разрешения для папок.** Новую папку можно разрешить отдельно; выбор неподходящей папки или отмена сохраняют файлы.
- **Проверка файла перед удалением.** Плагин проверяет путь, размер, время изменения и запись в MediaStore, чтобы не удалить подменённый файл.
- **Защита от чужих событий.** Подтверждения другого аккаунта, чата и посторонних сообщений не запускают удаление.
- **Работа в фоне.** Удаление выполняется в фоновой очереди; иконки создаются один раз, обработчиков отрисовки каждого кадра нет.
- **Штатное меню сохраняется.** ⋮ и переключатель Live Photo имеют отдельное место. При отключении плагина исходные размеры элементов восстанавливаются.

Удаляется оригинал **на устройстве**. Уже отправленное сообщение и его вложение в Telegram остаются в чате. Удаление с устройства не имеет встроенной отмены.

## Установка

1. Скачайте [best_gallery.plugin](https://github.com/Ovolsan/Best-gallery/releases/latest/download/best_gallery.plugin).
2. Откройте файл в exteraless и подтвердите установку.
3. Выдайте предложенные разрешения плагину, включите хуки на доверенном уровне и активируйте плагин.
4. Если установлен исходный **Delete From Gallery**, отключите его, чтобы его пункт удаления не дублировал новые действия.
5. Откройте чат → вложения → галерею и выберите фото или видео. Три кнопки появятся слева от ⋮.

После обновления проверьте разрешения и состояние хуков: приложение может запросить их заново. Обычная RAW-ссылка предназначена для скачивания; установку скачанного файла подтверждает exteraless.

## Удаление без повторного подтверждения

В настройках плагина есть переключатель **«Удалять без повторного подтверждения»**. Он включён по умолчанию.

При первом удалении из ещё не разрешённой папки Android откроет выбор папки. Выберите папку, содержащую выбранные файлы, и разрешите доступ. Можно разрешить родительскую папку, например `Pictures`, — тогда доступ будет действовать и для альбомов внутри неё.

Разрешение сохраняется после перезапуска приложения и телефона. При отправке с удалением запрос доступа появляется после подтверждения отправки. Пока доступ не выдан, оригиналы сохраняются.

Эта возможность реализована в плагине и доступна на других смартфонах с совместимым exteraless и системным поставщиком документов. **На каждом устройстве доступ к папкам нужно выдать отдельно.** На другом телефоне разрешения автоматически не появятся.

Android 11 и новее ограничивают выбор корня хранилища, корня `Download`, `Android/data` и `Android/obb`. Если папку нельзя разрешить, плагин использует штатное подтверждение удаления. Отключение настройки также возвращает штатный диалог. Подробнее: [доступ к папкам в Android](https://developer.android.com/training/data-storage/shared/documents-files).

Для проверенной сборки exteraless отдельное разрешение на доступ ко всем файлам отсутствует в манифесте; основной способ удаления без повторного запроса — разрешение нужной папки.

## Совместимость и ограничения

- Минимальная заявленная версия exteraless — **12.10.6**. Проверена сборка `12.10.6-00c14f4`; совместимость с будущими изменениями галереи требует отдельной проверки.
- Выбранные файлы должны уже находиться в локальной галерее устройства. Поиск изображений в интернете и ещё не сохранённые снимки камеры не подходят.
- Отправка с удалением доступна для **новых сообщений в обычных чатах**. Редактирование, секретные чаты и отправка по расписанию исключены.
- При ошибке, отмене или отсутствии полного подтверждения сервером оригиналы сохраняются. Следующую операцию можно начать после завершения текущей.
- Android может запросить системное подтверждение для папок, к которым нет сохранённого доступа.
- Работа с видео предусмотрена кодом. Живые проверки выполнены на JPG-фотографиях; видео, Live Photo, поворот экрана и другие версии Android отдельно на устройстве не проверялись.

## Проверка

На OnePlus 7 Pro с Android 11 и exteraless `12.10.6-00c14f4` проверены:

- положение кнопок при выборе одной и двух фотографий;
- разворачивание галереи, прокрутка и штатное меню ⋮;
- все три действия на специально созданных DEMO-файлах;
- отправка фото и документов в «Избранное», включая подписи и альбомы;
- удаление только после подтверждения всех отправок;
- отмена удаления и выбора папки;
- сохранение доступа к папке после перезапуска приложения и обновления плагина;
- отсутствие удалённых тестовых оригиналов в папке и MediaStore.

Подробный отчёт: [artifacts/verification.md](artifacts/verification.md). Локальные защитные проверки — **10 тестов**:

```sh
python -m unittest discover -s tests -v
python -m py_compile best_gallery.plugin
```

Плагин не требует сторонних Python-пакетов. Скрипт [tools/create_demo.py](tools/create_demo.py) для создания тестовых картинок требует Pillow.
