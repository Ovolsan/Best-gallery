Локальный журнал отправки и удаления: `phone-verification-1.2.0.log`; журналы не публикуются в репозитории. Все отправленные в этой проверке изображения были специально созданными DEMO-файлами. В журнале сначала подтверждаются все отправки, затем фиксируется удаление. Полные журналы приложения не отправлялись в чаты. Временные снимки телефона и XML интерфейса удалены.

Кнопки добавлены в штатный элемент меню ⋮: его движение между строкой выбранных файлов и верхней панелью выполняет exteraless. При выгрузке возвращаются исходные размеры меню, заголовков, штатного значка и кнопки Live Photo. Live Photo, поворот экрана и другие смартфоны отдельно на устройстве не проверялись.

Удаление без повторного запроса реализовано в плагине через сохранённый доступ Android к папке. На другом смартфоне папки нужно разрешить заново; ограничения Android для корня `Download` сохраняются. Живая проверка выполнена только на указанном телефоне.

## Предыдущая проверка 1.1.2

Дата: 10 октября 2026. exteraless `12.10.6-00c14f4`, Android 11, API 30.

| Сценарий | Результат |
| --- | --- |
| Три кнопки в заголовке между счётчиком и ⋮ | Проверено на телефоне; у корзины используется штатный `msg_delete` |
| Отмена системного удаления | Оригиналы и выделение сохранены |
| Фото → «Избранное» → удаление | Два DEMO-фото отправлены альбомом, удалены после подтверждения всех сообщений |
| Файлы → «Избранное» → удаление | Два JPG отправлены документами с исходными именами и подписью |
| Отмена первого выбора папки | Все DEMO-файлы и выделение сохранены |
| Разовое разрешение папки `Pictures` | Сохранено через `takePersistableUriPermission`; два DEMO-файла удалены через DocumentsContract |
| Повторная отправка фото после перезапуска | Альбом с подписью `DEMO_Best_gallery_media`; два оригинала удалены без окна удаления |
| Повторная отправка файлами | Имена `best_gallery_demo_9.jpg`, `best_gallery_demo_10.jpg`, подпись `DEMO_Best_gallery_file_no_dialog`; два оригинала удалены без окна удаления |
| Очистка MediaStore | Все 10 тестовых оригиналов отсутствуют и в папке, и в MediaStore |
| Настройка плагина | Переключатель удаления без повторного подтверждения включён; разрешения плагина 5/5 |
| Локальные тесты | 10 проверок: ACK всех файлов, чужие события, расписание, коллизии путей, границы папки/тома, отмены |

Свежие строки собственного журнала плагина после перезапуска сохранены локально в `phone-verification.log`. Журналы не отправлялись в чаты и не публикуются в репозитории. В «Избранное» отправлялись только специально созданные тестовые изображения; удалялись только эти тестовые оригиналы.

Системный доступ ко всем файлам не включён: текущая сборка не заявляет разрешение в манифесте, настройка Android недоступна. Для удаления без постоянного запроса используется разрешённая пользователем папка. Корень `Download` и другие ограниченные Android расположения сохраняют системное подтверждение.

Видеофайлы, потеря сети, большой альбом на телефоне, секретные чаты, редактирование и расписание в живом тесте не проверялись. Защитные условия для посторонних ACK, частичных подтверждений, расписания и отмен проверены локально; плагин исключает неподдерживаемые режимы перед отправкой.

SHA-256 доставленного `.plugin` и файла на телефоне совпадает:

`f7ebe1f3fd3aeb0dccb408bc9e51831dc86f517e6055e5c0e63ecba16cd1f47a`
